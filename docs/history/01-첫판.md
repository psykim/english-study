# 1장 — 첫 판 설계 (2026-11-12)

요청: 구독 중인 유튜브 채널(에스텔잉글리쉬)의 모든 영어 교육 영상을 순서대로 쉽게 보며 공부할 웹앱, 맥과 안드로이드폰에서.

## 결재 (사용자 선택)
1. 올릴 곳 — **인터넷 주소로 공개**(GitHub Pages). 집 와이파이 전용 안은 기각.
2. 진도 — **맥·폰 공유**(Supabase 무료). 기기별 따로 안은 기각.
3. 기본 순서 — **오래된 것부터**. 최신순은 화면에서 바꿀 수 있게, 재생목록은 칩으로.

## 결정과 이유
- **빌드 없는 정적 파일** — 화면 하나짜리 앱이라 프레임워크·번들러가 필요 없다. 고치면 곧 배포물.
- **저장소 공개** — GitHub 무료 요금제의 Pages는 공개 저장소에서만 된다. 담긴 것은 공개 영상 목록과 공개용 키뿐.
- **로그인 대신 열쇠** — 기기가 32자 무작위 열쇠를 만들고 QR 주소(`#k=`)로 다른 기기에 넘긴다. 표는 RLS로 잠그고
  함수 두 개만 연다(열쇠를 모르면 읽을 수 없음). 줄 수 상한 200·줄 크기 상한으로 남용을 막는다.
- **합치기 규칙** — 영상마다 「나중에 고친 쪽이 이긴다」. 두 기기를 번갈아 써도 진도가 사라지지 않는다.
- **목록은 yt-dlp로 받아 파일로** — YouTube Data API 키 없이 된다. 올린 날짜는 받지 않고 채널 표시 순서를 뒤집어 쓴다.
- 재생목록 속 비공개·삭제 영상 36건은 목록에서 뺐다.

## 채널 추가 (같은 날, v0.2)
사용자가 두 번째 구독 채널 「제니리 영어」를 요청. 자료 형식을 `channels[]`로 바꾸고 목록 열쇠를 `채널/목록`으로 했다.
진도는 영상 ID 기준이라 그대로 유지된다. 채널을 합친 한 줄 목록 대신 **채널 탭**을 택한 이유: 「순서대로」가 채널 안에서만 뜻이 있다.
